# E-Svitlo Суми

Графики отключений света: выбор очереди, временная шкала и часы отключений на сегодня и завтра.

## Запуск в Portainer

**Stacks → Add stack → Repository**:

- **Repository URL:** `https://github.com/Kerber0ss/esvitlo-web`
- **Repository reference:** `refs/heads/main`
- **Compose path:** `compose.yaml`

Нажми **Deploy the stack**. Страница: `http://IP_СЕРВЕРА:5178`.

Docker-образ: `ghcr.io/kerber0ss/esvitlo-web:latest` · `linux/amd64`.
